# Conduct Research — Output Format (Reference)

The full research report template extracted from `SKILL.md` to keep the main
file under 200 lines. Load this file when starting a new deep or scoped
investigation, when handing off to Content Writer / SEO Analyst, or when
training a new Researcher.
