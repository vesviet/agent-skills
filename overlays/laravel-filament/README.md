# Laravel Filament Overlay

Generic, reusable conventions for any Laravel 11+ project using Filament v3 admin, Livewire 3 interactive islands, and Blade static rendering. This overlay is tech-stack-specific but project-agnostic.

## Tech Stack Coverage

- **Framework:** Laravel 11 (PHP 8.2+)
- **Admin:** Filament PHP v3
- **Frontend:** Blade + Livewire 3 + Alpine.js
- **Database:** PostgreSQL / MySQL
- **Media:** Spatie Media Library (optional)
- **Testing:** Pest PHP / PHPUnit

## Included

- `rules/laravel-conventions.md` — Architecture, DB integrity, Filament, Livewire, testing standards
- `skills/develop-laravel-feature/` — Generic skill for building features in this stack

This overlay should be composed with the global core and optionally with a project-specific overlay.
